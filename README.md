# 류성열 | Backend Developer

치열한 몰입을 통해, 높은 성과(28팀 중 1등, 최우수팀 선정, 신규 서비스 출시·운영 성공)를 도출하는 개발자 류성열입니다.<br>
학부(AI 서비스 개발 학과 프로젝트, 개발 동아리)->단기 심화 부트캠프(3개월)->핀테크 스타트업(7개월) 경험을 기반으로 동연차 개발자들에 비해 프로젝트 감각이 뛰어납니다.      
핀테크 스타트업에서 "가맹점-카드사-협력사 시스템-카드 시스템-자사 정산 시스템"을 연결하는 B2C 카드 서비스를 초기 개발(MVP)-Alpha Test(그룹사 임직원 70명 대상)-출시·운영(사전 예약 35,000명)을 경험하며 0->1 실무 경험을 보유하고 있습니다.<br>

특히 AI 기반 업무를 선호하며, 실무에서 Codex 기반으로 개발 Workflow의 60%를 준자동화하며 6개월간 116개 업무 티켓을 처리했습니다.
